# ExcaliaShopApi

A simple Java application that retrieves and processes the data from the Excalia public API. 

This Maven project uses the Jackson library to parse and process JSON data.

- [Excalia](https://excalia.fr/)
- [Excalia API](https://excalia.fr/api-public)
- [Jackson 2.22.2](https://mvnrepository.com/artifact/com.fasterxml.jackson.core/jackson-databind/2.22.2)
